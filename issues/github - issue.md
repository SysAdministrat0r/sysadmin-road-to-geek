# GitHub Issue: Can't Delete Branch

**Problem:**  
I had two branches in my repo and couldn't delete the one I didn’t need because it was set as the default.

**Solution:**  
- Went to GitHub repository settings → "Branches"
- Changed the default branch to the one I want to keep
- Deleted the unwanted branch via the web interface (trash bin icon)

**Lesson:**  
You can’t delete the default branch.  
Always change the default first, then delete the extra branch.
