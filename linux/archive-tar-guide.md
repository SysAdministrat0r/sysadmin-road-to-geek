# Using tar on Linux

## Create an archive:
```bash
tar -cf archive.tar file1 file2
````

## List files in an archive:

```bash
tar -tvf archive.tar
```

## Extract all files from an archive:

```bash
tar -xf archive.tar
```

## Create a gzipped archive:

```bash
tar -czf archive.tar.gz file1 file2
```

## Extract a gzipped archive:

```bash
tar -xzf archive.tar.gz
```
